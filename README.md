# ⚡ Pulse — 스마트폰 개인 클라우드와 웹 데스크톱

Pulse는 남는 안드로이드 스마트폰을 Termux에서 개인 서버로 사용하는 프로젝트입니다.
현재 버전은 **v2.0.1**입니다. Python/Flask 단일 서버가 Pulse Cloud와 Pulse OS를 제공합니다.

## 설치 및 최초 로그인

```bash
pkg update -y
pkg install -y git python
git clone https://github.com/leesunkwon/termux-cloud.git
cd termux-cloud
./install.sh
```

설치 중 관리자 계정을 등록합니다. 비밀번호는 12자 이상이며 화면에 표시되지 않습니다.
기존 설치에서 업데이트했거나 계정을 추가하려면 프로젝트 폴더에서 실행하세요.

```bash
python3 setup-auth.py
./stop.sh
./start.sh --bg
```

`setup-auth.py`에서 `admin` 또는 `viewer` 권한을 선택합니다. 같은 계정 이름으로 다시 등록하면 비밀번호와 권한을 변경합니다. 계정 변경 후 서버를 재시작해야 하며 기존 로그인 세션은 무효화됩니다. 관리자 계정 없이 조회 계정만 남기는 설정은 허용하지 않습니다.

계정이 등록되지 않은 서버는 파일과 관리 API를 잠급니다. 계정 정보는 프로젝트의 `.pulse/accounts.json`에 해시된 비밀번호와 세션 서명 키로 저장되며 Git에서 제외됩니다. 해당 폴더를 외부에 공유하지 마세요. 비밀번호를 잊으면 서버의 Termux에서 같은 계정을 다시 등록할 수 있습니다.

| 권한 | 제공 기능 |
|---|---|
| 관리자 (`admin`) | 파일 업로드·편집·이동·휴지통 관리, 서버 명령 실행, 업데이트, Linux 데스크톱 연결 |
| 조회 (`viewer`) | 공용 보관함의 파일 목록·미리보기·다운로드, 시스템 상태 조회 |

계정별 보관함 분리는 제공하지 않습니다. 관리자 터미널은 서버 사용자 권한으로 실제 명령을 실행합니다. noVNC는 별도 서비스이므로 VNC 비밀번호를 설정해야 하며 Pulse 로그인만으로 noVNC 포트가 보호되지는 않습니다.

## 전역 단축 명령어 등록

신규 설치 시 자동 등록합니다. 이미 설치한 스마트폰에서는 최신 코드를 받은 후 한 번만 실행하세요.

```bash
cd ~/termux-cloud
git pull --ff-only origin main
bash install-cli.sh
```

이후 어떤 폴더에서든 아래 명령을 사용할 수 있습니다.

```bash
termux-cloud account     # 계정 생성 / 비밀번호·권한 변경
termux-cloud --bg        # 백그라운드 서버 시작
termux-cloud status      # 서버 상태·접속 주소·최근 로그
termux-cloud stop        # 서버 종료
termux-cloud restart     # 백그라운드 재시작 (계정 변경 후 실행)
termux-cloud update      # 최신 코드 다운로드 후 백그라운드 재시작
termux-cloud logs -f     # 실시간 로그 (Ctrl+C로 로그 보기만 종료)
termux-cloud help        # 전체 명령어 확인
```

`termux-cloud`만 입력하면 포그라운드 실행입니다. 최초 시작 시 계정이 없으면 터미널에서 등록을 진행합니다. `start`, `restart`, `update` 뒤에 `--bg`, `--port 3000` 등의 실행 옵션을 전달할 수 있습니다. `restart`, `update`에 옵션을 생략하면 `--bg`가 적용됩니다.

전역 실행 파일은 Termux의 `$PREFIX/bin/termux-cloud`에 등록됩니다. 프로젝트 경로에 공백이 있어도 사용할 수 있고 등록을 반복해도 중복 항목이 생기지 않습니다. 명령 처리는 저장소의 `cli.sh`를 사용하므로 이후 Git 업데이트로 새 명령이 반영됩니다. 프로젝트를 옮겼다면 새 위치에서 `bash install-cli.sh`로 다시 등록하세요.

Linux/macOS에서는 `~/.local/bin`에 등록하며, 해당 경로가 PATH에 없으면 추가 명령을 안내합니다. 셸 설정 파일은 자동 변경하지 않습니다.

## 실행과 접속

```bash
./start.sh          # 포그라운드 실행
./start.sh --bg     # 백그라운드 실행
./status.sh        # 실행 상태
./stop.sh          # 이 프로젝트의 서버 종료
./update.sh --bg   # 최신 코드 다운로드 및 재시작
```

설치된 `termux-cloud` 단축 명령도 사용할 수 있습니다. 기본 포트는 3000입니다.
동일 Wi-Fi에서는 `http://스마트폰IP:3000`, 스마트폰 자체에서는 `http://localhost:3000`으로 접속합니다.
외부 접속은 HTTPS 터널 또는 개인 VPN을 사용하세요. HTTPS 전용 배포에서는 아래처럼 보안 쿠키를 활성화합니다. 이 설정에서는 HTTP 주소로 로그인 세션을 사용할 수 없습니다.

```bash
PULSE_HTTPS=1 ./start.sh --bg
```

Python 개발 환경에서도 동일한 설치·계정 등록 과정으로 실행합니다.

```bash
python3 -m pip install -r requirements.txt
python3 setup-auth.py
./start.sh
```

`node server.js`와 `npm start`는 호환 실행 경로입니다. 별도의 Express 구현 대신 같은 Python 서버를 실행하므로 Python과 Python 의존성이 필요합니다. 웹에서 자동 재시작하려면 `./start.sh`로 실행하세요.

## Pulse Cloud

- 폴더별 60개 단위 목록, 상단 브레드크럼(Breadcrumb) 경로 탐색 바 및 상위 폴더 바로가기, 서버 검색·종류 필터(폴더/사진/비디오/문서/오디오 등)·정렬.
- 상단 툴바 '+ 새 폴더' 원터치 생성, 폴더 카드/목록 바로 열기, 폴더 카드 위로 파일 드래그 앤 드롭 업로드 지원.
- 새 폴더, 이름 변경, 폴더 이동, 현재 페이지 다중 선택. 이동할 폴더는 미리 생성하세요.
- 삭제 항목은 숨김 휴지통에 보관합니다. 휴지통에서 복원하거나 영구 삭제할 수 있습니다.
- 같은 이름이 이미 있으면 복원을 중단하며, 부모 폴더를 삭제했다면 부모를 먼저 복원해야 합니다.
- 휴지통은 영구 삭제 전까지 디스크 공간을 사용합니다. 자동 삭제는 하지 않습니다.
- 업로드는 동시에 2개만 전송합니다. 요청당 최대 2GB이며 중단된 업로드 이어받기는 지원하지 않습니다.
- 텍스트 미리보기·편집은 2MB까지 지원합니다. Office 문서 등 바이너리 문서는 다운로드를 사용하세요.
- 숨김 파일·심볼릭 링크와 보관함 외부 경로는 웹 파일 API에서 접근하지 못합니다.

이미지 썸네일은 **선택 의존성 Pillow**가 설치된 경우 JPEG/PNG/WebP에 대해 생성합니다.
320px JPEG로 축소하고 최대 200개를 보관합니다. 30MB 또는 2,500만 화소를 넘는 이미지는 썸네일을 생략합니다. Pillow가 없으면 목록에는 파일 아이콘을 표시하며 원본 미리보기는 계속 사용할 수 있습니다.

```bash
python3 -m pip install Pillow  # 선택 사항. Termux에서는 빌드 의존성이 필요할 수 있음
```

## Pulse OS (가상 웹 데스크톱)

- **🔍 Spotlight 전역 검색 & 런처 (`Ctrl+Space`)**: 키보드 단축키로 앱 즉시 실행, 수식 계산, 파일 검색, 시스템 명령 실행.
- **👁️ Quick Look 빠른 파일 미리보기 (`Space`)**: Finder 또는 바탕화면에서 스페이스바로 이미지, 영상, 오디오, 텍스트/코드 즉시 팝업 및 방향키 연속 탐색.
- **🪟 Mission Control 멀티태스킹 뷰 (`F3`)**: 열려 있는 모든 창을 한눈에 볼 수 있는 부드러운 타일링 배치 및 1클릭 창 전환.
- **🖥️ 바탕화면 마키 다중 선택 & 바로가기**: 바탕화면 마우스 드래그 박스(Marquee Selection) 다중 선택 지원.
- **🎛️ macOS 통합 제어 센터**: 상단 메뉴바 팝오버를 통해 IP 복사, 화면 테마 순환, 배경화면 블러, 마스터 볼륨 및 하드웨어 통계 조절.
- **📝 스티커 메모 (Stickies)**: 4가지 파스텔 테마, 실시간 로컬 영구 자동 저장, 타이틀바 더블클릭 접기 지원 포스트잇 앱.
- **🎵 Pulse Music 플레이어**: 보관함 오디오 트랙 자동 감지, 회전 바이닐 레코드 비주얼, 시크바, 창 최소화 시에도 유지되는 백그라운드 오디오 재생.
- **⛵ Dock Magnification & 최소화 모션**: 마우스 호버 시 부드러운 곡선형 확대 효과 및 축소/빨려 들어가는 창 최소화 트랜지션 애니메이션.
- **창 관리 & 멀티태스킹**: 윈도우 좌/우 50% 분할 스냅(Window Snapping), 클릭한 위치에 정확히 뜨는 마우스 우클릭 macOS 컨텍스트 메뉴, 코드 신택스 하이라이팅 및 터미널 ANSI 컬러 지원.
- 터미널은 명령당 15초, 출력 1MB 제한과 중복 실행 방지를 제공합니다. 에디터는 파일 전환·창 닫기 시 미저장 변경을 확인합니다.
- 모바일에서는 독으로 앱을 전환하며 앱 하나를 전체화면으로 표시합니다. 화면 회전·브라우저 키보드 높이에 유연하게 대응합니다.

## 상세 서버 대시보드

상단의 중복 회전 아이콘을 제거했습니다. 전역 새로고침은 화면 데이터를 갱신하고, 관리자는 Git 최신 업데이트도 즉시 확인합니다. 수동 업데이트 확인은 5분 캐시를 건너뛰며 자동 확인은 캐시를 유지합니다. 업데이트 적용은 배너 또는 대시보드의 버전 관리 영역에서 실행합니다.

| 영역 | 확인할 수 있는 정보 |
|---|---|
| CPU | 기기 전체 / Pulse 프로세스 구분, 코어별 사용률, 1·5·15분 부하 평균, I/O 대기, 읽을 수 있는 주파수 |
| 프로세스 | 서버 PID·UID, CPU 시간·사용률, 현재 RSS·최대 RSS, 스레드, 파일 핸들·제한, 프로세스 디스크 읽기·쓰기 속도 |
| 메모리 | 전체·가용·미사용 메모리, 파일 캐시·버퍼·회수 가능 커널 캐시, 스왑 전체·여유 |
| 저장소 | 실제 경로·쓰기 권한, 가용·예약 공간, 아이노드, 종류별 파일 수, 휴지통·로그 크기 |
| 네트워크 | 브라우저 왕복 시간, 인터페이스별 누적/초당 송수신, 오류·드롭 |
| HTTP | 요청 수, 활성 요청, 최근 최대 300건 평균·P95 처리 시간, 4xx·5xx, 최근 1분 요청 빈도 |
| 기기 | 부팅 후 경과, 서버 시작·가동 시간, 커널·아키텍처·런타임, 배터리·충전·온도 센서 |
| 운영 | 파일·터미널·업데이트 작업 상태, 재시작 지원, 쿠키 설정, noVNC 로컬 TCP 포트 연결 여부 |

- 최근 최대 60개의 CPU·RSS 관측값을 그래프로 표시하고 진단 JSON을 저장할 수 있습니다. 최소 10초 간격으로 관측할 때만 기록하며 재시작 시 초기화됩니다. 조회 공백 90초 이상과 CPU 측정 범위 변경 구간은 그래프 선을 연결하지 않습니다.
- 대시보드 응답은 5초, 온도·주파수·휴지통·로그·noVNC 통계는 60초간 서버에서 재사용합니다. 휴지통 조사는 최대 5,000개 항목으로 제한하고 부분 수집 여부를 표시합니다.
- CPU·메모리·디스크의 높은 사용률, 서버 오류, 저장소 쓰기 권한 문제를 안내합니다. 조회가 실패하면 마지막 성공 데이터임을 표시합니다.
- Android 버전과 SELinux 정책에 따라 `/proc/stat`, `/proc/net/dev`, 온도 센서 등이 차단될 수 있습니다. 추가 권한이나 루트를 자동 요청하지 않으며, 지원하지 않는 항목은 사유를 표시합니다.
- **Pulse 프로세스 CPU는 스마트폰 전체 CPU가 아닙니다.** 상단은 전체 코어 용량을 기준으로 0~100%, 프로세스 상세는 1코어=100% 기준입니다. 터미널 명령 등 자식 프로세스는 포함하지 않습니다. RSS를 읽지 못하면 최대 RSS를 현재 메모리로 대체하지 않습니다.
- 네트워크 통계는 기기 인터페이스 전체의 값으로 Pulse 전용 트래픽이 아닙니다. HTTP 처리 시간은 응답 헤더 생성까지이며 파일 스트리밍 전송 시간은 제외합니다. 요청 통계에는 대시보드 조회도 포함되며, 높은 요청량으로 표본이 잘린 요청 빈도는 ‘최소’로 표시합니다.
- 진단 JSON에는 서버 경로·네트워크 등 운영 정보가 들어가므로 외부 공유 전 내용을 확인하세요. 비밀번호·세션 키·명령 내용·요청 본문은 수집하지 않습니다.

## Linux 데스크톱

```bash
./setup-desktop.sh start
```

기본 noVNC 포트는 6080이며 `VNC_PORT`로 바꿀 수 있습니다. 서버와 스크립트에 같은 값을 전달하세요. Pulse OS의 Linux 창에서 **연결 주소**를 지정하거나 서버에 `VNC_PUBLIC_URL`을 설정할 수 있습니다.

```bash
VNC_PORT=6081 ./setup-desktop.sh start
VNC_PORT=6081 VNC_PUBLIC_URL=https://desktop.example.com/vnc.html ./start.sh --bg
```

HTTPS 페이지에서는 HTTP noVNC 연결을 차단하고 안내합니다. 외부 터널로 Pulse에 접속해도 noVNC 포트는 별도로 연결해야 합니다. Linux 창의 ‘새 탭으로 열기’도 설정한 주소를 사용합니다.

## 업데이트와 버전 관리

웹 업데이트는 **다운로드 → 재시작 → 새 서버 응답 확인**으로 진행합니다. 커밋하지 않은 변경이나 분기 충돌이 있으면 적용을 중단합니다. 다운로드 성공 후 서버가 직접 재시작을 예약하므로 브라우저의 추가 요청이 필요하지 않습니다. 파일·터미널 작업 중이거나 관리 모드가 아니면 다운로드 전에 중단합니다. 관리 모드가 아니라면 스마트폰 Termux에서 `termux-cloud restart`를 한 번 실행하세요. 기존 버전에서 이번 재시작 수정 코드를 처음 적용할 때도 Termux에서 재시작해야 실행 중인 서버 코드가 바뀝니다. Python 의존성이 바뀌는 릴리즈는 Termux에서 `./update.sh --bg`를 사용하세요.

자동 업데이트 확인은 활성 탭에서 5분 간격으로 진행하며, 서버도 결과를 5분간 재사용합니다.
코드를 수정할 때는 [CHANGELOG.md](CHANGELOG.md)에 변경 사항을 추가하고 함께 커밋합니다. 버전을 올리면 `app.py`, `package.json`, 이 문서도 함께 갱신합니다.

## 주요 파일

| 파일 | 역할 |
|---|---|
| `app.py` | 서버 실행, 터미널, 모니터링, 업데이트 API |
| `pulse_metrics.py`, `public/js/dashboard.js` | 제한된 자원 수집, 진단 상세·추이·내보내기 |
| `pulse_auth.py`, `setup-auth.py` | 로그인·권한·CSRF 검증 및 로컬 계정 등록 |
| `pulse_files.py` | 경로 검증, 폴더·파일·휴지통·썸네일 API |
| `public/js/pulse.js` | 로그인, 공통 대화상자, 아이콘과 화면 높이 관리 |
| `public/js/app.js` | Cloud·OS 화면과 앱 동작 |
| `process.sh`, `processctl.py` | 프로젝트 경로·실행 인자 확인 및 서버·리로더 종료 |
| `uploads/` | 기본 보관함 (`STORAGE_PATH`로 변경 가능) |

운영 환경 상세 설정은 [guide_termux.md](guide_termux.md)를 참고하세요.

화면 전환·OS 창·대화상자·카드·버튼에 짧은 공통 애니메이션을 사용합니다. 모바일은 시간을 단축하며, 기기의 동작 줄이기 설정을 켜면 애니메이션과 전환을 끕니다. Pulse 아이콘 원본에는 별도 장식이나 반복 효과를 추가하지 않습니다.
